🔌 API Documentation

Complete API reference for Hospital Management System

🧍 Patients API

GET /api/patients/
Get all patients (with pagination)
GET /api/patients/{id}/
Get specific patient details
POST /api/patients/
Create new patient
PUT /api/patients/{id}/
Update patient information
DELETE /api/patients/{id}/
Delete patient
GET /api/patients/count/
Get total patient count
GET /api/patients/search/?q={query}
Search patients by name, email, phone, or medical ID

👨‍⚕️ Doctors API

GET /api/doctors/
Get all doctors
GET /api/doctors/available/
Get only available doctors
GET /api/doctors/by_specialization/?specialization={spec}
Filter doctors by specialization

📅 Appointments API

GET /api/appointments/
Get all appointments
GET /api/appointments/today/
Get today's appointments
GET /api/appointments/upcoming/
Get all upcoming appointments
GET /api/appointments/recent/
Get 10 most recent appointments
GET /api/appointments/by_date_range/?start_date={date}&end_date={date}
Filter appointments by date range
GET /api/appointments/by_status/?status={status}
Filter by status (Scheduled, Completed, Cancelled)

📋 Medical Records API

GET /api/medical/records/
Get all medical records
GET /api/medical/records/by_patient/?patient_id={id}
Get medical records for specific patient

💊 Prescriptions API

GET /api/medical/prescriptions/
Get all prescriptions
GET /api/medical/prescriptions/by_patient/?patient_id={id}
Get prescriptions for specific patient

🧪 Lab Tests API

GET /api/medical/lab-tests/
Get all lab tests
GET /api/medical/lab-tests/pending/
Get all pending lab tests

💰 Invoices API

GET /api/medical/invoices/
Get all invoices
GET /api/medical/invoices/unpaid/
Get all unpaid invoices
GET /api/medical/invoices/total_revenue/
Get total revenue collected
